# Code of Conduct

## Our Standards

This project is an academic and collaborative workspace. Everyone contributing to it is expected to:

- Communicate respectfully and constructively.
- Give credit for ideas, data, code, and analysis work.
- Avoid harassment, discriminatory language, or personal attacks.
- Keep feedback focused on the work, not the person.
- Treat classmates, lecturers, reviewers, and external readers with professionalism.

## Unacceptable Behavior

Unacceptable behavior includes:

- Sharing private or sensitive information without permission.
- Publishing credentials, API keys, passwords, or private data.
- Misrepresenting authorship or academic contribution.
- Using the repository to target, shame, or harass individuals.

## Reporting

For academic matters, raise concerns with the project team first where appropriate. If the concern relates to grading, conduct, safety, or privacy, escalate it through the relevant Singapore Polytechnic module or school channel.

## Enforcement

Maintainers may remove inappropriate content, request revisions, or restrict contribution access when behavior harms the project or its contributors.
