# Privacy and Ethics

The data includes names, post text, engagement counts, and post links. Even when this information comes from a class project or public platform, it should be handled carefully.

## Guidelines

- Share only what is necessary for academic review.
- Do not publish private credentials, access tokens, or unpublished personal information.
- Review names and links before public release.
- Keep analysis conclusions proportionate to the dataset size and context.
- Avoid using engagement data to mock, target, or rank individuals unfairly.

## Data Handling

Raw data stays in `data/raw/`. If a cleaned or anonymized dataset is created later, place it in a separate documented folder such as `data/processed/` and explain the transformation steps.
