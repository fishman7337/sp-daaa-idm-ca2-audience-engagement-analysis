## Project Scope

The project studies engagement behavior from a collected post dataset. The analysis focuses on comments, reactions, views, posting day, posting time, and selected post comparisons.

## Repository Name

The working folder is still `IDM`, but the documented project name is **SP Digital Marketing Engagement Analytics** to make the purpose clearer to future readers.
